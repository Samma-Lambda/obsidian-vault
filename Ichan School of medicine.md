My goal as a participant in the Summer Research Training Program in Biomedical Big Data Science is to gain experience with data pipelines in a biomedical context, develop user-friendly and accessible tools for researchers without programming backgrounds, and enhance my ability to apply statistical analysis techniques to biomedical data.

My interest in biomedical data pipelines began in my database management class. While I find databases in general interesting, I am particularly interested in genetic databases due to the high-fidelity computing they require. For my final project, I created a small mock genetic database. I then implemented the Burrows-Wheeler Transform to improve memory usage and speed up substring queries. I found the data structures and algorithms used within this project so satisfying that I have continued to work on this as a personal project to this day. 

Beyond database management, I also enjoy creating tools that help others explore their data more effectively. I have experience with this from the biophysics research group I joined this last semester.  As the only member with extensive programming experience, I have focused on building easy-to-use tools for my group members to use. One example of this is an automated pipeline I created that processes microscopy data from our Myosin VI gliding filament assay, tracks filament locations, and outputs them into a CSV. With this data, and in collaboration with the biologists and physicists on the team, we have been able to perform topological data analysis and hypothesis testing on the movement of these filaments.

This has been my favorite project so far, and I would be excited to bring the skills I have developed to the Icahn School of Medicine. Since my university is a low-research institution, I have limited access to opportunities like this on campus. I hope to join this program to build useful computational tools and help make data analysis more accessible.
