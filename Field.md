# Field Definition
A field is a ring with unity where every element except the zero element has a multiplicative inverse. This effectively allows you to "Divide" by every element(except zero). Examples include 
- The real numbers 
- Matrices with determinate $1$ 
- The complex plane 

Because we have the ability to divide it gives us a nice algorithm called the Chinese Remainder Theorem
[[Chinese Remainder Theorem]]

# Field Extensions 
There are two different types of field extensions 
- **Algebraic:** An example of this type of extension would be the complex plane to the real numbers. An algebraic extension is by defining an element to represent the roof of an irreducible polynomial. For example $i$ comes from the root of $x^2+1$ 
- **Transendental:** Similarly to a transcendental numbers a transcendental field extension is a field extension that adds an transendental number  
These field extensions have a variety of uses
