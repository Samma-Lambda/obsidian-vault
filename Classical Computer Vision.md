Classical computer vision is the act of classifying, altering, and rendering images using hand made feature vectors. 
# Feature Vectors
Feature vectors are random variable from image space into another space. Simple examples could be counting the number of pixels above a certain blue threshold while others can be massively complicated. These features are then fed into some machine learning classifier to more easily curve fit. 
## Color Histograms
Color histograms are exactly they sound like. You create bins and then count the number of pixels that are contained in each bin. Often it is useful to normalize these histograms to prevent different sizes of images. Each bin becomes a dimension to the vector
